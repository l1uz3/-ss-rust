# Shadowsocks-Rust 一键管理脚本

支持 Debian / Ubuntu / Alpine 等主流 Linux 系统，支持自定义端口、加密方式（含 2022 系列），自动生成ss://格式节点链接。

---

### 海外机器安装 / 管理

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/l1uz3/-ss-rust/main/install.s)
```

### 国内机器加速安装 / 管理

```bash
bash <(curl -fsSL https://ghproxy.net/https://raw.githubusercontent.com/l1uz3/-ss-rust/main/install.sh)
```
